# Fotografias — como adicionar

Nenhuma fotografia profissional de Gabriel foi anexada a este projeto, então o
site hoje exibe um placeholder premium (monograma "GB") em todo lugar que
esperaria uma foto. Assim que os arquivos abaixo forem adicionados nesta
pasta **com exatamente estes nomes**, eles substituem o placeholder
automaticamente — nenhuma alteração de código é necessária.

| Arquivo                  | Usado em                    | Enquadramento sugerido                          | Proporção   |
| ------------------------- | ---------------------------- | ------------------------------------------------ | ----------- |
| `gabriel-hero.jpg`        | Hero da home + heros das ferramentas | Foto frontal ou em ângulo, plano médio, fundo neutro | vertical 3:4 (funciona bem em desktop e mobile) |
| `gabriel-about.jpg`       | Seção "Sobre Gabriel Bavaresco"       | Foto sentado, mais próxima e pessoal              | vertical 4:5 |
| `og-cover.jpg`            | Preview ao compartilhar o link (WhatsApp/LinkedIn/Instagram) | Foto + composição horizontal              | 1200×630px  |

Recomendações técnicas:

- Exportar em `.jpg` otimizado para web (qualidade ~80, sem metadados EXIF desnecessários).
- Manter abaixo de ~300KB por imagem sempre que possível (LCP/performance — seção 39 do briefing).
- Resolução mínima recomendada: 1200px no maior lado.
